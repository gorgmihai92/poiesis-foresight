# poiesis-foresight

Foresight from what a project already holds: which signals to keep, whether a yearly series moved against its own
past, how often such moves went on, contrasting scenarios, forecasts with a date that are scored later, and
signposts to watch. The `foresight` skill picks a playbook; scripts compute the numbers; the agents
`foresight-analyst` and `forecaster` run one part each.

The plugin of [Poiesis Foresight](https://github.com/gorgmihai92/poiesis-foresight), one of the five products in
the Poiesis Toolkit: Research collects, Insight connects, Foresight anticipates, Frontier explores, Design creates
([Poiesis Research](https://github.com/gorgmihai92/poiesis-research), [Poiesis
Insight](https://github.com/gorgmihai92/poiesis-insight), [Poiesis
Frontier](https://github.com/gorgmihai92/poiesis-frontier), [Poiesis
Design](https://github.com/gorgmihai92/poiesis-design)).

```
/plugin marketplace add gorgmihai92/poiesis-foresight
/plugin install poiesis-foresight@poiesis-foresight
```
