# Poiesis Foresight

Foresight for Claude Code: what is changing, what it could mean for the future, and what to watch. It reads signals
and yearly counts, builds contrasting scenarios, writes forecasts with a date and scores them when the date passes.

This repository is being set up. The plugin is not here yet and cannot be installed from this branch: version
0.1.0 is built on a branch and arrives in one pull request.

Poiesis Foresight is part of the Poiesis Toolkit, next to
[Poiesis Research](https://github.com/gorgmihai92/poiesis-research),
[Poiesis Insight](https://github.com/gorgmihai92/poiesis-insight),
[Poiesis Frontier](https://github.com/gorgmihai92/poiesis-frontier) and
[Poiesis Design](https://github.com/gorgmihai92/poiesis-design).
